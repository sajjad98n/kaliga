پس از زدن دکمه، برنامه ایمیل کاربر باز می‌شود تا پیام برای ایمیل برگزارکننده ارسال شود.

logo.png، team1.png تا team12.png، pic1.jpg تا pic12.jpg، img4.png و mp1.mp4

فرم پیشنهادات:
- فایل feedback-supabase.sql را یک بار در SQL Editor پروژه Supabase اجرا کنید.
- فرم صفحه اصلی پیام‌ها را در جدول feedbacks ثبت می‌کند.
- راه ارتباطی اختیاری داخل متن همان پیام ذخیره می‌شود.
- دسترسی خواندن عمومی برای پیام‌ها ایجاد نشده است.
